## 這些該不該加進海報？

**建議：不要。** 三個理由：

1. 海報已經是滿版 1 頁 A3（內容底緣 40.63 cm，邊界 40.9 cm），再塞任何一段都會被迫縮字或掉到第二頁。
2. 海報的功能是「三公尺外吸引人停下來、三十秒看懂在做什麼」，不是技術手冊。細節是**你講出來的**，不是印上去的——評審看到你不用看板子就能答，比板子上印滿字更加分。
3. 這些資料的價值在於**被問到才拿出來**。全印上去等於把自己的問答彈藥先打光，而且評審會轉去問更邊角的問題。

**唯一建議補進海報的兩處**（都不佔空間）：

- ④ 硬體層那行改精確：`LDS-01 360° 雷射雷達 │ Dynamixel XL430 伺服馬達（內建 4096 ticks/圈 磁性編碼器）│ OpenCR 1.0 控制板（換算里程）`。現在寫「輪子編碼器」像是獨立零件，實際上編碼器在馬達裡（見 [02](02_硬體規格與里程來源.md)）。
- ③↔④ 的上行箭頭標籤 `雷射距離、輪子里程（USB 序列）` → `雷射距離、編碼器 ticks（USB 序列）`，因為 odom 是 OpenCR 算完才上來的，不是硬體直接給里程。

## 建議的使用方式

- 口試前一天把 [05_預想問答.md](05_預想問答.md) 從頭到尾念一遍，其他份當字典查。
- 站海報前手機開著 [03_參數速查與選擇理由.md](03_參數速查與選擇理由.md)，被問到數字直接報。
- 被問到你不確定的，答「這部分我們沒有實測，目前是採用官方預設值」比硬掰安全——見 [06](06_已知限制與未來工作.md)。
