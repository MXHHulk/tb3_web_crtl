## 一、安全邊距膨脹（形態學 Dilation）

### 1.1 要解決的問題

TurtleBot3 不是一個點，它有實體大小（直徑約 0.20 m）。地圖上障礙物邊界是「牆真正的
位置」，若路徑貼牆走，機器人中心到牆距離為 0 → 車體撞牆。

**解法**：把地圖上的障礙往外「長胖」一圈，厚度 = 機器人半徑。規劃器只要讓
**機器人中心點**避開膨脹後的障礙，實際車體就自然離牆有安全距離。這在機器人學裡稱為
**configuration-space（C-space）膨脹**。

### 1.2 形態學膨脹的數學定義

膨脹的對象是**二值影像**（每格只有 True/False），需要一個**結構元素（核, kernel）**
定義膨脹的形狀與範圍。膨脹規則一句話：

> 把結構元素的中心放到影像每一格上；只要核覆蓋範圍內**至少碰到一個 True**，
> 中心那格輸出就是 True。

集合式（A = 障礙集合，B = 結構元素）：

```
A ⊕ B = { z | (B_hat)_z ∩ A ≠ ∅ }
```

即：把核 B 平移到位置 z，若平移後的核與障礙 A 有任何重疊，z 就納入結果。
效果就是障礙往外長胖一圈，厚度 = 核半徑 r。

### 1.3 一維直覺

核寬 3（半徑 1），障礙在 index 3：

```
index:  0  1  2  3  4  5  6
原始:   0  0  0  1  0  0  0

核中心放 index2 → 覆蓋{1,2,3} → 碰到障礙 → 輸出 1
核中心放 index3 → 覆蓋{2,3,4} → 碰到障礙 → 輸出 1
核中心放 index4 → 覆蓋{3,4,5} → 碰到障礙 → 輸出 1

結果:   0  0  1  1  1  0  0
              └──┬──┘  原本 1 格 → 3 格，左右各長胖 1 格（= 核半徑）
```

### 1.4 二維：核形狀決定膨脹形狀

用**全 True 的方形核**，障礙往八方向都長胖 r 格，角落填滿（方形膨脹）：

```
5×5 方核 (r=2)，單一障礙點 X：

原始 (. free, X 障礙)        膨脹後 (# 新增安全邊距)
. . . . . . .                . . . . . . .
. . . . . . .                . # # # # # .
. . . X . . .        →       . # # X # # .
. . . . . . .                . # # # # # .
. . . . . . .                . . . . . . .
```

換十字形/圓盤核，長出來就是十字/圓形——這正是「規劃用」與「顯示用」兩份膨脹形狀
不同的原因（見 1.7）。

### 1.5 規劃用實作逐行拆解

`scripts/coverage_planner.py:12-26`：

```python
def apply_safety_margin(data, margin, resolution):
    obs = data == 100                              # ① 障礙布林遮罩
    r = max(1, round(margin / resolution))         # ② 公尺 → 格數
    kern = np.ones((2 * r + 1, 2 * r + 1), bool)   # ③ 造 (2r+1)² 方核
    return binary_dilation(obs, structure=kern)    # ④ SciPy 執行膨脹
```

- **① `obs = data == 100`**：`data` 值域 `{-1 未知, 0 自由, 100 障礙}`，篩出障礙格。
  `-1`（未知）在此不算障礙。
- **② `r = max(1, round(margin/resolution))`**：膨脹只認格數，這行做單位換算。
  `margin=0.10 m`（機器人半徑, `coverage_planner.py:9`）、`resolution=0.05 m/格`
  → `r = round(0.10/0.05) = 2` 格。`max(1, …)` 保證至少膨脹 1 格。
- **③ `kern = np.ones((2r+1, 2r+1), bool)`**：半徑 r → 直徑 `2r+1`（奇數，有唯一中心）。
  r=2 → 5×5 全 True 方核。
- **④ `binary_dilation(obs, structure=kern)`**：SciPy 執行膨脹，回傳
  `True = 障礙 + 安全邊距` 的布林陣列。**這份有實際避障效果。**

### 1.6 膨脹結果怎麼被用

`scripts/map_server.py:362-363`（`/coverage/start` 路由）：

```python
safe_obs = apply_safety_margin(raw['data'], COV_MARGIN, meta['resolution'])
free     = (raw['data'] == 0) & ~safe_obs   # 原本自由 且 不在膨脹障礙內
```

`~safe_obs` 是布林反相；原本自由但落在牆邊 r 格內的格子被 `& ~safe_obs` 扣掉，
不會被排進牛耕路點 → 機器人永不被要求走到貼牆位置。

### 1.7 對照：顯示用膨脹（不影響走路）

`scripts/map_server.py:123, 135-137` 另有一份**純視覺化**膨脹：

```python
kern = np.ones((3, 3), dtype=bool)                  # 固定 3×3（半徑1）
gray_d[binary_dilation(obs, kern, MORPH_ITER)] = 0  # MORPH_ITER=2 次
```

輸出成 `/map_dilated.png` 給前端看，**不參與規劃**。與規劃用的差異：

| | 規劃用 `apply_safety_margin` | 顯示用 `map_dilated` |
|---|---|---|
| 檔案:行 | `coverage_planner.py:12` | `map_server.py:137` |
| 核 | 5×5 方形（由 margin 動態算） | 3×3 固定 |
| 疊代次數 | 1 次 | 2 次 |
| 膨脹形狀 | 方形 | 菱形（3×3 疊代擴散） |
| 作用 | 真的讓機器人避障 | 只畫給人看 |

`map_server.py:45-47` 註解說明此設計：顯示膨脹刻意用機器人半徑當半徑，
避免把窄出口在畫面上誤畫成封死。

## 二、PCA 主軸對齊（協方差 + 特徵分解）

### 2.1 要解決的問題

牛耕是一條條平行線來回掃。問題：**平行線該朝哪個方向？** 若房間是斜的、或斜走廊，
硬沿地圖 X/Y 軸掃，會切出一堆短掃描線、狂轉彎。最有效率的方向是**沿空間最長的方向掃**
（掃描線最少、轉彎最少）。

PCA（主成分分析）能從一堆點的分布中，自動算出「延伸最長的方向」與「最短的方向」。

```
斜走廊的自由格：            PCA 找出：
      . . .                     ↗ 長軸 (axis_a, sweep 掃描方向)
    . . . .                   ↗
  . . . .                   ↗  ↘ 短軸 (axis_b, step 換行方向)
. . . .
```

### 2.2 PCA 的數學原理（四步）

核心命題：**一堆點的協方差矩陣，其特徵向量就是資料的主軸方向，
對應特徵值就是該方向上的延伸程度（變異數）。**

1. **去中心化**：算重心，每點減重心，讓資料以原點為中心（只保留形狀/方向）。
2. **協方差矩陣**（2D 為 2×2）：
   ```
   C = | Var(x)     Cov(x,y) |
       | Cov(x,y)   Var(y)   |
   ```
   對角線 = 各方向散布程度；非對角線 = x,y 是否一起變化（傾斜程度，斜空間不為 0）。
3. **特徵分解** `C v = λ v`：得到 2 組（特徵值 λ, 特徵向量 v），兩軸互相垂直。
   - 特徵向量 v = 主軸方向；特徵值 λ = 該方向的變異數（延伸多長）。
4. **排序挑軸**：λ 最大 → 長軸（sweep）；λ 最小 → 短軸（step，垂直長軸）。

### 2.3 逐行對照

`scripts/coverage_planner.py:49-62`：

```python
center           = pts.mean(axis=0)                 # 步驟1：重心
diffs            = pts - center                      # 步驟1：去中心化
eigvals, eigvecs = np.linalg.eigh(np.cov(diffs.T))   # 步驟2+3：協方差 + 特徵分解
axis_a = eigvecs[:, np.argmax(eigvals)]   # 步驟4：長軸 = sweep
axis_b = eigvecs[:, np.argmin(eigvals)]   # 步驟4：短軸 = step
if axis_a[0] < 0: axis_a = -axis_a         # 方向正規化
if axis_b[1] < 0: axis_b = -axis_b
proj_a = diffs @ axis_a    # 投影到長軸
proj_b = diffs @ axis_b    # 投影到短軸
```

其中 `pts` 由 `coverage_planner.py:45-47` 把所有可走格 (`free==True`) 轉世界座標而得。

- **`np.cov(diffs.T)`**：`diffs` 形狀 `(N,2)`，`.T` 轉 `(2,N)`（`np.cov` 要求每列一個變數），
  回傳 2×2 協方差矩陣。
- **`np.linalg.eigh(...)`**：專給**對稱矩陣**的特徵分解（協方差必對稱，用 `eigh` 比 `eig`
  快且穩、保證實數）。`eigvals` 由小到大排好；`eigvecs` 的**每一欄**是一個特徵向量。
- **`eigvecs[:, np.argmax(eigvals)]`**：取最大特徵值那欄 = 延伸最長方向 = sweep。
- **方向正規化**：特徵向量正負號任意（v 與 -v 等價）。強制長軸指 +x、短軸指 +y，
  讓路點順序穩定、每次結果一致（不會今天從左掃、明天從右掃）。
- **`proj_a/proj_b = diffs @ axis`**：把每點點積投影到兩主軸，得到每點在 sweep/step 軸的
  座標。之後只在這個「沿空間長軸」的旋轉座標系裡思考，不必管地圖是否傾斜。

> 注意：本專案不是呼叫某個叫 PCA 的函式，而是用 `np.cov` + `np.linalg.eigh`
> **手動組出 PCA 流程**，再自行挑軸、正規化、投影——每步都是標準 PCA 教科書流程。

## 三、牛耕式覆蓋（投影分帶 + 蛇行）

### 3.1 概念

有了 PCA 的長軸（sweep）與短軸（step），牛耕就是：**沿短軸每隔 `spacing` 切一條「帶」，
每條帶取長軸上最小/最大投影當兩端，逐條交替方向，連成蛇行路線。**

### 3.2 逐行對照

`scripts/coverage_planner.py:64-84`：

```python
b_min, b_max = proj_b.min(), proj_b.max()
b   = b_min + spacing / 2           # 第一條線內縮半格，兩端對稱覆蓋
l2r = True
while b <= b_max + spacing / 2:
    mask = np.abs(proj_b - b) < spacing / 2       # 落在這條帶內的格
    if mask.any():
        a_vals  = proj_a[mask]
        p_start = center + a_vals.min() * axis_a + b * axis_b   # 帶的一端
        p_end   = center + a_vals.max() * axis_a + b * axis_b   # 另一端
        if l2r: waypoints += [p_start, p_end]
        else:   waypoints += [p_end, p_start]      # 反向 → 走完直接接下一條
        l2r = not l2r
    b += spacing
```

- **`b` 從 `b_min + spacing/2` 起跳**：第一條掃描線離邊界內縮半格，讓兩端對稱覆蓋。
- **`mask = |proj_b - b| < spacing/2`**：找出短軸座標落在當前帶 `[b-半格, b+半格]` 的格子。
- **`p_start/p_end`**：從旋轉座標系換回世界座標——`center + (長軸位移)*axis_a +
  (短軸位移)*axis_b`。取該帶長軸投影的 min/max 當掃描線兩端。
- **`l2r` 交替翻轉**：奇數條左→右、偶數條右→左，走完一條的終點正好接下一條起點 →
  蛇行不空跑。

### 3.3 間距的巧思：10% 重疊

`SPACING = 0.18 m`（`coverage_planner.py:8`），而機器人覆蓋寬度約 `0.20 m`。
刻意讓間距略小於覆蓋寬度 → **留約 10% 重疊**，相鄰掃描線之間不留縫、達成全覆蓋。

### 3.4 效能：全向量化

整段幾乎全是 numpy 向量化（`np.where`、投影點積、布林遮罩），沒有逐格 Python 迴圈
（唯一的 `while` 只迭代「帶數」，通常數十次）。所以就算地圖上萬格也能瞬間算完——
這是「每次收到新地圖都能即時重算路徑」而不卡頓的基礎。

## 四、三者的分工

跟一般工程慣例一致——**演算法核心交給函式庫，我們負責準備輸入、設參數、用結果**：

| 演算法 | 函式庫負責（核心運算） | 我們負責（準備 + 決策 + 應用） |
|--------|------------------------|-------------------------------|
| 膨脹 | `scipy.ndimage.binary_dilation` 掃描每格 | 造障礙遮罩、公尺→格數換算、造核、扣可走區 |
| PCA | `np.cov`、`np.linalg.eigh` 算協方差與特徵分解 | 去中心化、挑長/短軸、正負號正規化、投影 |
| 牛耕 | `np.where`、numpy 遮罩/點積 | 分帶邏輯、交替方向、間距重疊、座標換回 |

膨脹是「一行 `binary_dilation` 全包」；PCA 是「用兩個 NumPy 函式手動組流程」；
牛耕則幾乎全是我們自己的向量化邏輯。三者共同構成「能對齊任意方向四邊形、
又算得夠快可即時重算」的覆蓋規劃核心。
