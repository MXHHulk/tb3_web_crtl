# 導演稿：成果影片動畫簡報（2026-11-25）

來源：`../簡報生成.md`（旁白、數據、出處以那份為準）。風格定案見 `direction-approved.md` 第三次調整。
每鏡一個 HTML（`scenes/NN-*.html`），網頁簡報按一下播一段（2026-11-25 使用者確認：要簡報動畫、不要影片檔）；需要時仍可用 `tools/render.mjs` 匯出單頁 MP4。

## 全片規則
- 一鏡只講一件事；主角一定是內容（路徑、地圖、數字），不用框裝
- 跨鏡持續存在的主角：**牛耕光帶**（霓虹黃綠掃描線）。開場畫出來，PCA／cell／問題頁都是它的狀態變化
- 動作語言：線條「畫出來」（stroke 由頭到尾）、數字「跳到位」（快速計數、ease-out）、字「推進」（由下往上 12px＋淡入，220–400 ms）
- 每鏡分 1–3 段，每段播完停住等下一次點擊（`steps`）
- 還沒拍的實機畫面：暗色出血區＋一行「🎥 待拍：…」，不放框
- 不加 BGM／SFX；不加浮水印

## 視覺密度條款
- 每鏡至少一個佔畫面 40% 以上的內容主角（路徑、地圖、巨字）
- 文字最多三層：一句標題、一句說明、一行出處
- 數字一律標「實車／離線／示意」與次數
