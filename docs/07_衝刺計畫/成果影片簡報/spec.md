# 設計 spec：成果影片簡報

來源：`../簡報生成.md`（逐頁規格、旁白、數據出處都以那份為準，本檔只寫設計要用的部分）

| 項目 | 內容 |
|---|---|
| 是什麼 | 3 分鐘專題成果影片的畫面（簡報＋實機片段＋旁白），共 10 頁 |
| 受眾 | 系展評審與參觀者：看影片、不一定懂 ROS；一頁停留 10–30 秒 |
| 核心信息 | ① 車子不必擺正，自動建圖後完成全覆蓋 ② 三個實作問題怎麼解 ③ 覆蓋率 71% → 97.7%（實車、同場地） |
| 情感基調 | 工程、可信、乾淨；數字都標「實車／離線模擬」與次數 |
| 輸出格式 | 16:9，HTML 每頁 960×540pt（= LAYOUT_WIDE，可匯出可編輯 PPTX）＋ PDF；影片錄製用 1920×1080 |
| 已知約束 | 沿用海報配色：標題列 `#b9dcfc`、強調 `#1F4E79`、底色 `#e1f1ff`、箭頭 `#8ABAE6`；一頁一個重點；圖為主字為輔；`【待填】` 不得填假設值 |
| 字體 | Noto Sans TC／Noto Serif TC（Windows 已安裝）、數字 Bahnschrift；全是本機字體，PPTX 打開不掉字 |
| 主角素材 | `assets/path_*.png`：由 `tools/gen_figs.py` 呼叫專案的 `coverage_planner.plan()` 實際算出的路徑，不是手畫示意。實機俯拍與網頁截圖待週四週五拍攝後替換 |
| 代表頁 | P1 開場封面、P7 問題三（DWA vs 自寫循跡數據對照） |
