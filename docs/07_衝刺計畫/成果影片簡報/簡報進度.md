## 3. 拿到最新成果後要做的事（照順序）

1. **對數據**：逐項比對上表「用到的數據」，以最新版為準；`簡報生成.md` 也要同步改，兩邊不能不一致
2. **改文字與數字**：都在 `tools/build_scenes.py`（每頁一段 `scene(...)`，數字直接寫在 HTML 字串與 `count` 的 `to:`）
3. **換規劃圖**：若 `coverage_planner.py` 有改，重跑 `python tools/gen_data.py`（路徑會自動跟著新演算法）
4. **放實機影片**：檔案放 `assets/`，在 11 頁（必要時 04 頁）把「REC 待拍」區換成 `<video autoplay muted loop>`
5. **填總表**：12 頁的 `data` 陣列，【待填】換成實測值；PCA 那列等修完 cell 碎裂再決定放不放
6. 重跑 `python tools/build_scenes.py` → `node tools/frames.mjs scenes/NN-*.html steps` 逐段截圖看 → `node tools/test_play.mjs`
