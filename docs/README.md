# docs — 專案文件總索引

本專案所有文件的**單一入口**。原本散在 `help/` 與 `note/` 的東西已依用途分成六類。

```
docs/
├── 01_學習資料/     看懂專案怎麼運作（觀念、架構、演算法、程式對照）
├── 02_論文/         論文成品與產生腳本
├── 03_海報/         專題海報、系統架構圖、口試答辯資料
├── 04_簡報/         教學簡報成品與產生腳本
├── 05_開發日志/     每次改程式的 devlog
└── 06_規範/         版本控制／commit 規範
```

> 產生腳本（`gen_*.py`）都跟它的產出物放在同一層，直接 `python gen_xxx.py` 即可重新產生，
> 輸出檔會寫回腳本所在資料夾。

---

## 01_學習資料 — 想搞懂專案就從這裡看

建議閱讀順序：

| 順序 | 文件 | 內容 |
|:----:|------|------|
| 1 | [教學報告.md](01_學習資料/教學報告.md) | **主線文件**。從問題定義、背景知識、系統總覽到模組逐一拆解，最完整的一份 |
| 2 | [專案設計架構.md](01_學習資料/專案設計架構.md) | 最初的設計文件：硬體、環境、模組職責劃分 |
| 3 | [coverage_algorithm.md](01_學習資料/coverage_algorithm.md) | 牛耕式覆蓋的**流程串接**：規劃 → 執行 → 網頁即時呈現 |
| 4 | [演算法原理.md](01_學習資料/演算法原理.md) | 三大核心演算法的**數學原理與逐行程式對照**（安全邊距膨脹、PCA 主軸對齊、牛耕覆蓋） |
| 5 | [ros_topics_nodes.md](01_學習資料/ros_topics_nodes.md) | 全專案 Node / Topic / Publisher / Subscriber 統整 |
| 6 | [web_architecture.md](01_學習資料/web_architecture.md) | `map_server.py`（Flask 後端）＋ `web/index.html`（前端）怎麼串 |
| 7 | [路徑規劃架構與假完成診斷.md](01_學習資料/路徑規劃架構與假完成診斷.md) | 「還有空間沒走到卻顯示完成」的成因追查與修正方向 |

其中 3 與 4 是互補的：**3 看流程、4 看數學**。
